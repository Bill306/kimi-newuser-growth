# Kimi 新用户 7 日会员转化方案

AI 产品经理作业：提升 Kimi 新用户（注册 7 天内）的会员转化率，同时保证留存不下降。

**在线体验**：[可交互原型](https://bill306.github.io/kimi-newuser-growth/site/prototype.html) ｜ [网页版报告](https://bill306.github.io/kimi-newuser-growth/)

## 一句话结论

新用户 7 天里有两个决定性时刻：

- **注册后的头几分钟**（P0）：问 2 个点选问题，把一个和用户自己有关的任务直接填进输入框，按一下发送就能拿到成果，直达 Aha。
- **额度用完的那一刻**（P1）：先帮用户做一部分，再推付费，并给不付费的人留一条免费退路。

前一个时刻决定有多少人走到后一个时刻。

## 运行原型

```bash
open site/prototype.html
```

或者在仓库根目录起一个静态服务器：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000/site/prototype.html`。

**体验路径**：默认从「第 1 天：注册成功」开始。选职业和想做的事，输入框里会填好专属任务，按发送键或 Enter 就开始。之后可以快进到「第 3 天：额度触顶」。右侧可以切换场景和实验组 / 对照组，并实时显示埋点事件和本次会话漏斗。
