# Kimi 新用户 7 日会员转化方案

AI 产品经理作业：提升 Kimi 新用户（注册 7 天内）的会员转化率，同时保证留存不下降。

## 交付物

| 部分 | 文件 | 说明 |
|---|---|---|
| 文档 | [`方案文档.pdf`](方案文档.pdf) / [`方案文档.docx`](方案文档.docx) / [`方案文档.md`](方案文档.md) | 用户旅程分析、指标体系、三个需求与优先级、实验设计 |
| 原型 | [`site/prototype.html`](site/prototype.html) | 需求 A「任务续航」付费引导的可交互原型，单文件，无需构建 |
| 录屏 | [`原型录屏.mp4`](原型录屏.mp4) | 58 秒，覆盖实验组付费路径、免费退路和对照组 |
| 网页版报告 | [`site/index.html`](site/index.html) | 文档的网页版，含走查截图和原型入口 |

## 一句话结论

付费引导应该出现在用户「正在做一件重要的事、额度不够了」的那一刻。把这一刻从「额度不足」的报错，改成「先帮你做一部分，再告诉你还差多少、怎么补上」，并给不付费的人留一条免费退路。

## 运行原型

```bash
open site/prototype.html
```

或者在仓库根目录起一个静态服务器：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000/site/prototype.html`。

**体验路径**：默认停在「第 3 天：额度触顶」，点手机里的蓝色发送键推进剧情。右侧可以切换实验组 / 对照组，或者回到第 1 天。右侧实时显示埋点事件和本次会话漏斗。
